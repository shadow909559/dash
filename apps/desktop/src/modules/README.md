# DASH Frontend Modules

This directory contains all feature modules for the DASH desktop application frontend.

## Structure

- **dashboard/** - Main dashboard and overview
- **chat/** - Chat interface and conversation management
- **memory/** - Memory and knowledge base visualization
- **projects/** - Project management interface
- **automation/** - Workflow and automation builder
- **plugins/** - Plugin management and marketplace
- **voice/** - Voice interface and controls
- **settings/** - Application settings and configuration

Each module is self-contained with its own components, hooks, and utilities.
