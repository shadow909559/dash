# DASH Backend AI Services

This directory contains all AI-related backend services for the DASH desktop application.

## Structure

- **memory/** - Memory management and persistence services
- **automation/** - Desktop automation and workflow services
- **projects/** - Project and workspace management
- **plugins/** - Plugin system for extensibility
- **voice/** - Voice recognition and synthesis services
- **agents/** - AI agent implementations
  - **planner/** - Task planning and orchestration
  - **coder/** - Code generation and analysis
  - **researcher/** - Research and information gathering
  - **browser/** - Browser automation
  - **system/** - System integration and management
- **providers/** - LLM provider integrations
  - **ollama/** - Local Ollama models
  - **openai/** - OpenAI GPT models
  - **anthropic/** - Anthropic Claude models
